# 📋 SCDR-001: Definición de Alcance

**Versión:** 0.1 (Experimental)
**Fecha:** 14 de Septiembre de 2026

---

## 1. PROPÓSITO

Este documento define el alcance operacional de la especificación SCDR-001.

---

## 2. ¿QUÉ ES SCDR-001?

Es una especificación técnica experimental que define cómo:

| # | Define |
| :-: | :--- |
| 01 | **Emitir** una credencial documental verificable |
| 02 | **Anclar** la credencial en blockchain |
| 03 | **Registrar** la credencial en un testigo legal |
| 04 | **Verificar** la autenticidad de una credencial |
| 05 | **Revocar** una credencial |

---

## 3. ¿QUÉ NO ES SCDR-001?

| # | Lo que NO es |
| :-: | :--- |
| 01 | ❌ Certificación oficial ISO ni NOM |
| 02 | ❌ Asesoría legal |
| 03 | ❌ Sistema de identidad |
| 04 | ❌ Sistema de reputación |
| 05 | ❌ Blockchain propia |

---

## 4. ALCANCE OPERACIONAL

### ✅ ¿Qué SÍ certifica?

- Existencia (fecha/hora específica)
- Integridad (no modificado)
- Autoría declarada
- Fecha cierta (VATES)
- Anclaje inmutable (Ethereum)

### ❌ ¿Qué NO certifica?

- Autoría real
- Originalidad
- Calidad
- Cumplimiento ético
- Reputación

---

## 5. EXCLUSIONES

SCDR-001 NO se aplica a:
- Documentos de identidad oficial
- Documentos legales vinculantes
- Documentos médicos
- Documentos financieros
- Documentos gubernamentales
